Technical Methodology & System Architecture

Comprehensive explanation of model pipeline, preprocessing behavior, and classification thresholds

Academic Documentation
Academic Prototype & Synthetic Training Data Disclaimer

FakeGuard AI is developed as an academic engineering prototype. The detection model is trained on a synthetic dataset structured to simulate common behavioral patterns of social media bots and authentic accounts. Performance on synthetic demonstration datasets does not constitute empirical proof of real-world Instagram accuracy. Real-world production deployment requires a representative, ethically collected, and manually audited dataset.

1. Machine Learning Pipeline Architecture

The system employs an end-to-end Scikit-learn Pipeline serialized using Joblib:

Input CSV / JSON Payload 10-column input (username separated)
→
Stage 1 Zero-Fill Preprocessing Prototype replaces missing numeric entries with 0
→
Stage 2 Pipeline SimpleImputer Median strategy imputer defensive safeguard
→
Stage 3 Random Forest Classifier 100 estimators, balanced class weights
→
Output Class Probability Suspicious probability estimate 0.0 – 1.0
Documentation of Imputation Interaction: Per the project report specifications, prototype data preprocessing fills missing numeric values with zero before prediction. The underlying Scikit-learn Pipeline additionally encapsulates a SimpleImputer(strategy='median') step. This dual architecture ensures that even when arbitrary external inputs bypass the prototype preprocessor, the serialized pipeline gracefully handles missing values without runtime failure.

2. The Nine Model Features

To preserve user privacy and prevent lexical bias, the username is used strictly as an identifier and is never fed into the Random Forest model. Exactly 9 numeric features are analyzed:

  • account_age_days: Total active lifespan of the account in days.
  • followers_count: Number of accounts subscribed to this profile.
  • following_count: Number of accounts this profile follows.
  • posts_count: Total number of public media posts.
  • avg_likes: Mean number of likes received per post.
  • avg_comments: Mean number of comments received per post.
  • has_profile_pic: Binary indicator (1 = custom avatar, 0 = default placeholder).
  • bio_length: Total character length of profile biography.
  • repetitive_comments: Frequency count of detected duplicate/spam comments.

3. Exact Risk Categorization Thresholds

The Random Forest output probability $P(\text{Suspicious})$ is mapped to three risk categories:

Probability Range Classification Recommended Action
Below 40% (< 0.40) Low Risk Account verified as exhibiting organic social patterns.
40% to below 70% [0.40, 0.70) Medium Risk Anomalous engagement; manual review or secondary verification recommended.
70% or above (≥ 0.70) High Risk Strong statistical pattern matching automated bot farms or ghost profiles.

4. Independent Rule-Based Warning Indicators

FakeGuard AI features an independent explanation module that evaluates deterministic heuristic rules in parallel with the machine learning model:

1. Fresh Account Age Trigger: account_age_days < 30

Flags newly registered accounts which frequently account for automated bot creation surges.

2. Follow-Ratio Asymmetry Trigger: following / followers > 2.5

Identifies mass-follow / follow-for-follow scripts attempting to artificially inflate follower counts.

3. Ghost Engagement Trigger: likes / followers < 0.005

Highlights accounts with high follower counts but negligible interaction, indicative of purchased fake followers.

4. Missing Profile Picture Trigger: has_profile_pic == 0

Detects placeholder avatars common to throwaway accounts and mass spam bots.

5. Repetitive Comment Spam Trigger: repetitive_comments ≥ 3

Flags recurring identical promotional comments across multiple target profiles.

Important Notice on Heuristic Separation: These warning signals are evaluated by a standalone rule module. They are not causal explanations of the Random Forest model's internal tree splits. The Random Forest generates its probability non-linearly across the complete 9-dimensional hyperspace.
